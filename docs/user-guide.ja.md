# Trimletをはじめて使う

[アプリ紹介へ戻る](../README.ja.md) · [English](user-guide.md)

このページは、コードを書かずにWindows版を使う方向けです。

## 1. アプリを用意する

[Windows版のZIPをダウンロード](https://github.com/jydie5/Trimlet/releases/download/v0.4.0-beta.1/Trimlet-0.4.0-beta.1-win-x64.zip)し、右クリックの「すべて展開」でフォルダーへ取り出してください。ZIPの中から直接起動せず、展開先のファイルを一緒に残します。

対象はWindowsのx64版です。開発者のWindows 11環境で確認しています。Windows 10やARM版などの動作検証は未完了です。Mac版の完成済みダウンロードはまだありません。

## 2. 動画処理用のファイルを追加する

現ベータ版にはFFmpegという動画処理ツールが入っていません。初回だけ別途用意します。**プログラミングやPowerShellコマンドは不要ですが、ファイルの追加は必要です。**

1. [FFmpeg公式サイトのダウンロード案内](https://ffmpeg.org/download.html)を開き、「Windows EXE Files」から案内される配布元へ進みます。ページ上部の「Download Source Code」は選びません。実行ファイルの配布元は第三者です。
2. Windows x64用のビルド済みパッケージを入手して展開します。追加のDLLを必要としない「static」版が、この手順には適しています。
3. 展開した中の、通常は `bin` フォルダーにある `ffmpeg.exe` と `ffprobe.exe` を、Trimletの `Trimlet.Windows.exe` と同じフォルダーにコピーします。
4. 配布元の利用条件を確認し、ライセンス文書も保管してください。個人で追加するこの手順は、FFmpeg入りTrimletを再配布するための案内ではありません。

すでにFFmpegを設定済みの場合は追加不要なことがあります。判断がつかなければ、[困っている内容を報告](https://github.com/jydie5/Trimlet/issues/new?template=bug_report.yml)してください。

## 3. 起動して切り出す

`Trimlet.Windows.exe` をダブルクリックします。.NETの追加インストールや、`.ps1` ファイルの実行は通常不要です。

1. **動画を開く**から元動画を選びます。
2. 開始したい位置へ移動し、**INを設定**を押します。
3. 終了したい位置へ移動し、**OUTを設定**を押します。終了は開始より後にしてください。
4. **シーケンスへ追加**を押すと、残すクリップとして登録されます。必要な区間の数だけ繰り返します。
5. クリップを並べ替え、**シーケンスを再生**で確認します。
6. **MP4を書き出す**を押し、保存先のフォルダーを選びます。

「高速」は速さを優先するため、切る位置が前後する場合があります。「正確」は選んだ位置を優先し、映像を変換するため時間がかかります。書き出し後は実際の動画を確認してください。

## 続きを保存する

**保存**で編集内容を `.trimlet` ファイルに保存します。再開するときは **プロジェクト → プロジェクトを開く** を使います。

プロジェクトは動画そのものを含みません。元動画も残し、移動するときは一緒に移動してください。Windows版では同じドライブに保存します。**まだ追加していないIN／OUTの選択は保存されません。**

## 起動できない・困ったとき

- **発行元の警告が出る：** このベータ版は未署名です。不明な配布元から入手したものは実行せず、上の公式リリースから取得したか確認してください。セキュリティ機能を無効にする必要はありません。不安があれば利用を止めてください。
- **.NETを要求される：** 最新の配布ZIPをすべて展開したか確認してください。開発用ビルドや古いEXEと混ぜないでください。
- **FFmpegが見つからない：** 2つのEXEがTrimletのEXEと同じフォルダーにあるか確認し、アプリを再起動します。
- **開けない／書き出せない動画がある：** 形式によって未対応の場合があります。まず短い動画で試してください。
- **報告する：** [不具合報告](https://github.com/jydie5/Trimlet/issues/new?template=bug_report.yml)にWindowsのバージョン、Trimletのバージョン、操作と表示された内容を書いてください。わからない項目は「不明」で構いません。個人の動画や名前の写った画像は添付しないでください。

重要な動画とプロジェクトはバックアップしてください。この版では、さまざまなパソコンや動画を使った検証がまだ十分ではありません。
