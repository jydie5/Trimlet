# Trimlet Mac 0.3 マルチ区間ヒューマンチェック

この確認のゴールは、1本の元動画から複数の必要区間を作り、順番にプレビューして、1本のMP4へ安全に書き出せることです。SwiftやXcodeの知識は不要です。

## 1. 起動

リポジトリ直下の`run-poc.command`をFinderでダブルクリックします。ターミナルでビルドした後、`dist/Trimlet.app`が起動します。

初回またはテスト動画を作り直す場合は、ターミナルでリポジトリへ移動して次を実行します。

```bash
./scripts/create-test-media.sh
```

用意される動画：

- `TestMedia/trimlet-sample.mp4`：8秒、30 fps、440 Hzと880 Hzの2音声
- `TestMedia/trimlet-realistic.m2ts`：同じ映像・2音声をM2TS／AC-3化
- `TestMedia/trimlet-long-5m10s.mp4`：進捗と長尺操作用

テスト動画は生成物であり、リポジトリには収録されません。

## 2. 再生と位置移動

1. 「動画を開く…」またはドラッグ＆ドロップで`trimlet-sample.mp4`を開きます。
2. 再生／一時停止を繰り返し、映像とボタン状態が一致することを確認します。
3. 左右キーで1フレーム、Shift＋左右キーで10フレーム、Option＋左右キーで5秒移動します。
4. スライダーで移動した直後にも、再生・停止・フレーム移動が反応することを確認します。
5. 再生／停止を通常速度で50回、続けて200～300 ms程度の間隔でも操作し、最後の操作と表示が一致するか確認します。

## 3. 複数区間を作る

次の3区間を、あえて出力順どおりに追加します。

1. 動画を開いた直後に、開始点と終了点がどちらも「未設定」で、②と③がまだ押せないことを確認します。
2. 5.0秒付近へ移動して「① 現在位置を開始に」、6.5秒付近へ移動して「② 現在位置を終了に」、「③ この範囲を残す」の順に操作します。
3. 追加後、開始／終了が「未設定」へ戻り、区間が下の「出力される区間」へ現れることを確認します。
4. 同じ順序で0.5～1.5秒、3.0～4.0秒も追加します。

確認項目：

- 説明書を読まなくても、①開始 → ②終了 → ③残す、の順番を画面から判断できる。
- 元動画の時間軸で、緑の開始点、赤の終了点、点線の作成中範囲、青の追加済み区間を区別できる。
- 区間カードにIN、OUT、区間時間が表示される。
- カードを選択すると見出しが「選択した区間を編集」へ変わり、その開始／終了が読み込まれる。
- 開始／終了を変えて「変更を保存」すると、そのカードだけが変わる。
- 「新しい区間に戻る」で、追加用の空の状態へ戻れる。
- 既存区間と重なる範囲は追加・更新できず、理由が表示される。
- 前後移動で出力順を変更できる。
- 削除、⌘Z、⇧⌘Zで、削除・順序・更新を取り消し／やり直しできる。
- 元動画のファイル日時と内容は変わらない。

## 4. 区間プレビュー

1. カードを選び「この区間を再生」し、終了点で止まることを確認します。
2. 「出力順に再生」を押します。
3. 区間間の不要部分を飛ばし、カードの並び順で3区間が再生されることを確認します。
4. 区間切り替え時に停止したままにならず、最後のOUTで停止することを確認します。
5. 連続プレビュー中にSpace、シーク、フレーム移動を行い、通常操作へ安全に戻れることを確認します。

## 5. 音声選択

1. 書き出し欄に音声Pickerが表示されることを確認します。
2. `jpn / Main 440 Hz`を選んで書き出します。
3. `eng / Alternate 880 Hz`へ切り替えて別名で書き出します。
4. 出力を再生し、音の高さが異なることを確認します。
5. M2TSでも2つの音声候補が表示され、選択した音声が出力されることを確認します。

## 6. Accurate複数区間書き出し

1. 「フレーム正確」を選びます。
2. 「MP4を書き出す…」から元動画と異なる名前を指定します。
3. ダイアログに区間番号、全体進捗、キャンセルが表示されることを確認します。
4. 完了後にFinderで表示し、3区間がカード順で1本に連結されていることを確認します。
5. 出力時間が画面の合計時間に近く、映像と選択音声が最後まで同期していることを確認します。
6. 長めの書き出しをキャンセルし、完成品に見える途中ファイルや`.partial`ファイルが残らないことを確認します。

## 7. Fast複数区間書き出し

1. 「高速」を選びます。
2. 各カードのオレンジ色の高速候補と、タイムライン上の候補枠を確認します。
3. 指定範囲より候補が広がる場合、その違いを事前に理解できるか確認します。
4. 書き出して、3区間がカード順で1本に連結されることを確認します。
5. 出力時間が指定区間の合計ではなく、高速候補の合計に近いことを確認します。
6. 「高速不可」と表示される区間がある場合、Fast書き出しが無効になり、Accurateを選べることを確認します。

## 8. M2TSと長尺確認

1. `trimlet-realistic.m2ts`を開き、プロキシ生成後に編集できることを確認します。
2. プロキシはプレビュー専用で、書き出しが元M2TSを使うことを確認します。
3. 複数区間、音声選択、Fast／Accurateを繰り返します。
4. `trimlet-long-5m10s.mp4`で3区間を作り、タイムライン操作、カード操作、進捗中のUIが固まらないことを確認します。

## 9. 評価してほしい点

各項目を「問題なし／少し迷う／分からない」で記録してください。

- ①開始 → ②終了 → ③残す、の操作順
- 新規区間作成と既存区間編集の違い
- 区間の追加、選択、更新、削除、並べ替え
- Undo／Redo
- 合計時間と出力順
- 選択区間と全区間プレビュー
- Fast候補と指定範囲の違い
- 音声トラック選択
- 区間ごとの進捗とキャンセル
- 長尺動画でのタイムライン精度
- 画面全体の密度、文字サイズ、軽さ

特に、説明を読まないと分からなかった操作、押しても変化が分からなかった操作、期待した区間順と出力が違った箇所を記録してください。

## 10. 既知の制限

- 現在は1本の元動画だけを扱います。複数素材やマルチトラック編集は対象外です。
- タイムラインのズーム、サムネイル、波形、区間端の直接ドラッグは未実装です。
- Accurate設定はH.264 VideoToolbox 12 Mbps／AAC 256 kbpsの暫定値です。
- VFRの表示フレーム移動はAVFoundation方式で、source PTS一覧による移動は未実装です。
- プロキシ容量表示と削除画面は未実装です。
- UI文字列の英語切り替え、署名、公証、DMG配布は未実装です。
