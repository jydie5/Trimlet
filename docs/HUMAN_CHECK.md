# Trimlet Mac 0.4 build 10 ヒューマンチェック

## Build 10 Timeline Interaction：最初に確認する項目

今回の受入対象は、ソースタイムライン上で再生位置とIN／OUT範囲を取り違えずに操作できることです。詳細な形状・当たり判定・状態は、[ソースタイムライン操作仕様](TIMELINE_INTERACTION_2026-09-09.md)を正本とします。Build 9の上下分離レイアウトは履歴であり、現行の合格条件ではありません。

ビルド10の実装と自動／オフスクリーン描画確認は完了しています。ライト／ダークの4状態を描画した[コンポーネント確認画像（ライト）](images/timeline-build10-light.png)と[コンポーネント確認画像（ダーク）](images/timeline-build10-dark.png)は、クリッピングやラベル衝突の確認用です。これらは実行中アプリのスクリーンショットではなく、ポインター／トラックパッド操作の合格を意味しません。以下の項目を実際のMac画面で行い、結果を「問題なし／少し迷う／分からない」で記録してください。

1. **INを固定してOUTへ進める。** 再生を停止し、現在位置で`I`または「INを設定」を押す。上段の目盛り・空白部分をクリックまたはドラッグして別位置へ移動し、INが動かないことを確認する。再生せずに`O`または「OUTを設定」を押し、紫の範囲と追加ボタンが有効になることを確認する。
2. **操作対象を取り違えない。** 上段と下段の範囲内部をクリック／ドラッグし、再生位置だけが動くことを確認する。INの左側の外向きグリップ、OUTの右側の外向きグリップをそれぞれドラッグし、対応する境界だけが動くこと、つかんだ瞬間にジャンプしないことを確認する。
3. **短い範囲でも調整する。** 48 pt未満に見える短い範囲を作り、IN／OUTのグリップを別々に狙えること、反対側を越えないこと、時間表示が実際の境界と一致することを確認する。範囲内部のドラッグで全体が移動（スリップ）しないことも確認する。
4. **補助操作を確認する。** `I`／`O`のキー表示、ホバー／ドラッグ中の対象名と時刻、二本指シークが見え、ボタンを押しても再生を要求されないことを確認する。ライト／ダーク表示でも色だけに頼らず意味が分かることを確認する。

ビルド、Coreチェック、共有契約、生成動画による書き出し検証は別途自動確認する。これらが成功しても、ポインターの当たり判定や視認性の人手確認を合格扱いにはしません。

以下の0.3チェックは従来の回帰項目です。0.4の既存UI確認記録は履歴として残し、Build 10の境界操作合格記録とは分けて扱います。

この確認のゴールは、1本の元動画から複数の必要区間を作り、順番にプレビューして、1本のMP4へ安全に書き出せることです。SwiftやXcodeの知識は不要です。

## 1. 起動

リポジトリ直下の`run-poc.command`をFinderでダブルクリックします。ターミナルでビルドした後、`dist/Trimlet.app`が起動します。

初回またはテスト動画を作り直す場合は、ターミナルでリポジトリへ移動して次を実行します。

```bash
./scripts/create-test-media.sh
```

用意される動画：

- `TestMedia/trimlet-sample.mp4`：8秒、30 fps、440 Hzと880 Hzの2音声
- `TestMedia/trimlet-realistic.m2ts`：同じ映像・2音声をM2TS／AC-3化
- `TestMedia/trimlet-long-5m10s.mp4`：進捗と長尺操作用

テスト動画は生成物であり、リポジトリには収録されません。

## 2. 再生と位置移動

1. 「動画を開く…」またはドラッグ＆ドロップで`trimlet-sample.mp4`を開きます。
2. 再生／一時停止を繰り返し、映像とボタン状態が一致することを確認します。
3. 左右キーで1フレーム、Shift＋左右キーで10フレーム、Option＋左右キーで5秒移動します。
4. スライダーで移動した直後にも、再生・停止・フレーム移動が反応することを確認します。
5. 再生／停止を通常速度で50回、続けて200～300 ms程度の間隔でも操作し、最後の操作と表示が一致するか確認します。
6. `L`を1～4回押し、順方向が1x、2x、4x、8xへ変わることを確認します。`J`を繰り返し、減速・停止・逆方向への切替を確認します。`K`で停止します。
7. 画面上に「J 逆再生」「K 停止」「L 順再生」と意味を含むボタンが見え、同じ操作ができること、現在速度の表示と映像の方向が一致することを確認します。
8. スライダーを掴んだまま左右へ大きく動かし、映像が追従すること、離した後の時刻とフレームが一致することを確認します。

## 3. 複数区間を作る

次の3つのサブクリップを、あえて出力順どおりに追加します。

1. 動画を開いた直後に、IN点とOUT点がどちらも「未設定」で、②と③がまだ押せないことを確認します。
2. 5.0秒付近へ移動して「① 現在位置をIN点に」、6.5秒付近へ移動して「② 現在位置をOUT点に」、「③ シーケンスへ追加」の順に操作します。
3. 追加後、IN／OUTが「未設定」へ戻り、クリップが下の「編集シーケンス」へ現れることを確認します。
4. 同じ順序で0.5～1.5秒、3.0～4.0秒も追加します。
5. 別の範囲を、画面ボタンではなく`I`でIN点、`O`でOUT点を設定して追加します。

確認項目：

- 説明書を読まなくても、①IN → ②OUT → ③シーケンスへ追加、の順番を画面から判断できる。
- IN設定ボタンに`I`、OUT設定ボタンに`O`のキー表示があり、ショートカットの意味を画面だけで判断できる。
- ソースタイムラインで、緑のIN点、赤のOUT点、紫＋点線の作成中範囲、青の追加済みクリップを区別できる。
- 有効なIN／OUTを決めると範囲が紫で塗られ、シーケンスへの追加成功後に同じ範囲が青へ変わる。
- クリップカードにIN、OUT、クリップ時間が表示される。
- 各カードにIN点付近の代表サムネイル、クリップ名、IN–OUT時間が表示される。
- カードを選択してクリップ名を変更でき、トリム後もその名前が保持される。
- カードを選択しただけでは見出しが「サブクリップを作成」のままで、既存クリップのIN／OUTが新規作成欄へ読み込まれない。
- 選択後に「トリム編集」を押したときだけ、見出しが「クリップをトリム」へ変わり、そのIN／OUTが読み込まれる。
- IN／OUTを変えて「トリムを適用」すると、そのクリップだけが変わる。
- 「新規サブクリップ」で、追加用の空の状態へ戻れる。
- 既存クリップと重なる範囲は追加・トリムできず、理由が表示される。
- クリップをドラッグすると、ドロップ先が強調され、編集シーケンスの順序が変わる。
- 並べ替え後もサムネイルとクリップ名が変わらず、時間だけを比較しなくても同じクリップを追跡できる。
- 既存カードを選択したまま新しいIN／OUTを設定すると、既存カードは変わらず、新しいカードが追加される。
- 前へ移動／後へ移動でも同じ順序変更ができる。
- 削除、⌘Z、⇧⌘Zで、削除・順序・更新を取り消し／やり直しできる。
- 元動画のファイル日時と内容は変わらない。

## 4. 区間プレビュー

1. カードを選び「クリップを再生」し、OUT点で止まることを確認します。
2. 「シーケンスを再生」を押します。
3. 区間間の不要部分を飛ばし、カードの並び順で3区間が再生されることを確認します。
4. 区間切り替え時に停止したままにならず、最後のOUTで停止することを確認します。
5. 連続プレビュー中にSpace、シーク、フレーム移動を行い、通常操作へ安全に戻れることを確認します。

## 5. 音声選択

1. 書き出し欄に音声Pickerが表示されることを確認します。
2. `jpn / Main 440 Hz`を選んで書き出します。
3. `eng / Alternate 880 Hz`へ切り替えて別名で書き出します。
4. 出力を再生し、音の高さが異なることを確認します。
5. M2TSでも2つの音声候補が表示され、選択した音声が出力されることを確認します。

## 6. Accurate複数区間書き出し

1. 「フレーム正確」を選びます。
2. 「MP4を書き出す…」から元動画と異なる名前を指定します。
3. ダイアログに区間番号、全体進捗、キャンセルが表示されることを確認します。
4. 完了後にFinderで表示し、3区間がカード順で1本に連結されていることを確認します。
5. 出力時間が画面の合計時間に近く、映像と選択音声が最後まで同期していることを確認します。
6. 長めの書き出しをキャンセルし、完成品に見える途中ファイルや`.partial`ファイルが残らないことを確認します。

## 7. Fast複数区間書き出し

1. 「高速」を選びます。
2. 各カードのオレンジ色の高速候補と、タイムライン上の候補枠を確認します。
3. 指定範囲より候補が広がる場合、その違いを事前に理解できるか確認します。
4. 書き出して、3区間がカード順で1本に連結されることを確認します。
5. 出力時間が指定区間の合計ではなく、高速候補の合計に近いことを確認します。
6. 「高速不可」と表示される区間がある場合、Fast書き出しが無効になり、Accurateを選べることを確認します。

## 8. プロジェクト保存と再開（0.4追加）

1. 3つのクリップを作り、1つを改名し、順番を入れ替えます。書き出しを「フレーム正確」、音声を2番目にします。
2. ヘッダーの「プロジェクト」→「保存」または⌘Sで`trimlet-check.trimlet`として保存します。
3. ヘッダーの「未保存」が消えることを確認します。クリップをもう一度並べ替え、「未保存」が戻ることを確認します。
4. ウインドウ左上の赤ボタンで閉じます。「保存／保存しない／キャンセル」が出ること、まず「キャンセル」で編集画面へ戻れることを確認します。同じ確認を⌘Qでも行います。
5. 保存して終了し、再起動後に「プロジェクトを開く…」から`trimlet-check.trimlet`を開きます。
6. クリップ数、UUIDに結び付く名前、順序、IN–OUT、フレーム正確、選択音声が保存時どおりで、サムネイルが再生成されることを確認します。
7. テスト用動画の複製を元動画として別プロジェクトを保存し、その複製だけをFinderで別フォルダへ移動します。プロジェクトを開くと再リンク画面が出ることを確認します。
8. 移動先の同じ動画を選び、プロジェクトが開いて「未保存」になること、保存後は次回自動で開くことを確認します。
9. 再リンク時に別の動画を選び、保存時と一致しない警告が出ることを確認します。「キャンセル」で現在の編集が失われないことを確認します。
10. 未保存の状態で別の動画またはプロジェクトを開き、「保存しない」と「キャンセル」がそれぞれ期待どおり動くことを確認します。

確認後、`.trimlet`をテキストエディタで開いても構いません。元動画の絶対パスや、サムネイル／プロキシ／書き出し先が記録されていないことを確認してください。

## 9. M2TSと長尺確認

1. `trimlet-realistic.m2ts`を開き、プロキシ生成後に編集できることを確認します。
2. プロキシはプレビュー専用で、書き出しが元M2TSを使うことを確認します。
3. 複数区間、音声選択、Fast／Accurateを繰り返します。
4. `trimlet-long-5m10s.mp4`で3区間を作り、タイムライン操作、カード操作、進捗中のUIが固まらないことを確認します。
5. 通常動画の読込後、キーフレーム解析がタイムライン内だけに表示され、全面パネルや「閉じる」を要求しないことを確認します。
6. M2TSのプロキシ生成中は進捗とキャンセルが表示され、成功後はクリックしなくても画面が編集可能になることを確認します。

## 10. 評価してほしい点

各項目を「問題なし／少し迷う／分からない」で記録してください。

- ①IN → ②OUT → ③シーケンスへ追加、の操作順
- 新規サブクリップ作成と既存クリップのトリムの違い
- クリップの追加、選択、トリム、削除、ドラッグ並べ替え
- Undo／Redo
- 合計時間と編集シーケンス順
- 選択区間と全区間プレビュー
- Fast候補と指定範囲の違い
- 音声トラック選択
- 区間ごとの進捗とキャンセル
- プロジェクトの保存、未保存表示、再開、再リンク
- 長尺動画でのタイムライン精度
- 画面全体の密度、文字サイズ、軽さ

特に、説明を読まないと分からなかった操作、押しても変化が分からなかった操作、期待した区間順と出力が違った箇所を記録してください。

## 11. 既知の制限

- 現在は1本の元動画だけを扱います。複数素材やマルチトラック編集は対象外です。
- 編集シーケンスはクリップを隙間なく並べる方式です。任意時刻への配置、空白、重なり、複数トラックは未実装です。
- Build 10ではソースタイムラインの直接シークとIN／OUT端の直接ドラッグを実装済みですが、人手確認が未完了です。連続フィルムストリップ、波形、ホバースキマーは未実装です。カードには1枚の代表サムネイルを表示します。
- Accurate設定はH.264 VideoToolbox 12 Mbps／AAC 256 kbpsの暫定値です。
- VFRの表示フレーム移動はAVFoundation方式で、source PTS一覧による移動は未実装です。
- プロキシ容量表示と削除画面は未実装です。
- `.trimlet`は元動画そのものを含みません。元動画を別の場所へ移すと再リンクが必要です。
- 作成途中の紫範囲、現在位置、Undo／Redo履歴はプロジェクトへ保存しません。
- UI文字列の英語切り替え、署名、公証、DMG配布は未実装です。
