# Trimlet Mac PoC 0.2 ヒューマンチェック

SwiftやXcodeの知識は不要です。通常のMacアプリとして触り、使い方が自然かを確認してください。

## 1. 起動

Finderで次を開きます。

リポジトリフォルダ内の`dist/Trimlet.app`です。

再ビルドしてから起動する場合は、Finderで次をダブルクリックします。

リポジトリ直下の`run-poc.command`です。

初回だけターミナル画面が表示され、ビルド完了後にTrimletが起動します。

## 2. 用意済みテスト動画

MP4の基本操作確認:

`TestMedia/trimlet-sample.mp4`

進捗表示の確認（5分10秒）:

`TestMedia/trimlet-long-5m10s.mp4`

M2TSプロキシとM2TS書き出し確認:

`TestMedia/trimlet-realistic.m2ts`

どちらも8秒のカラーパターンと音声を生成したテスト専用ファイルです。個人動画は含みません。

ファイルを再生成する場合は、ターミナルで次を実行します。

ターミナルでリポジトリフォルダへ移動し、`./scripts/create-test-media.sh`を実行します。

## 3. 基本操作チェック

1. 「動画を開く…」からMP4を選びます。ドラッグ＆ドロップも試します。
2. 映像、ファイル名、長さが表示されることを確認します。
3. 再生ボタンまたはSpaceで再生・一時停止します。
4. タイムラインをドラッグし、任意位置へ移動します。
5. 左右キー（1フレーム）、Shift＋左右キー（10フレーム）、Option＋左右キー（5秒）を試します。画面上の対応ボタンも試します。
6. 時刻表示がそれぞれの移動量に合って変化することを確認します。
7. 開始位置で`I`または「INを設定」を使います。
8. 終了位置へ移動し、`O`または「OUTを設定」を使います。
9. 青い選択範囲と選択時間が自然に理解できるか確認します。
10. 「選択範囲を再生」を押し、OUT点で止まることを確認します。
11. 再生と停止を50回ほど交互に押し、無反応やアイコンの食い違いがないか確認します。
12. タイムラインのオレンジ目盛り（キーフレーム）と、高速候補範囲が理解できるか確認します。

## 4. 書き出しチェック

### 高速・無劣化

1. 「高速・無劣化」を選びます。
2. 「MP4を書き出す…」を押します。
3. 元動画とは別の名前で保存します。
4. 処理中ダイアログ、進捗、キャンセルが分かることを確認します。
5. 完了ダイアログに「Finderで表示」と「閉じる」が出ることを確認します。
6. 出力をQuickTime Playerで開き、映像と音声を確認します。

高速モードはキーフレーム制約により、指定範囲より少し長くなる場合があります。これはPoCで表示している説明どおりの挙動です。

### フレーム正確

同じ範囲を「フレーム正確」で書き出します。開始・終了位置が高速モードより指定に近いか、画質と処理時間が許容できるかを確認します。

`trimlet-long-5m10s.mp4`でもフレーム正確を選び、進捗が単調に増え、処理中も画面が応答することを確認します。全範囲を書き出す必要がなければ、キャンセル確認だけでも構いません。

## 5. M2TSチェック

1. `trimlet-realistic.m2ts`を開きます。
2. 「プレビュー用プロキシを生成しています…」の後に映像が表示されることを確認します。
3. 画面下部に「プロキシでプレビュー中（書き出しは原本を使用）」と表示されることを確認します。
4. MP4と同じ再生、フレーム移動、IN/OUT操作を試します。
5. 高速モードとフレーム正確モードでMP4を書き出します。
6. 両方に映像と音声があることを確認します。

## 6. 評価してほしい点

各項目を「問題なし／少し迷う／分からない」で評価してください。

- 動画を開く方法
- 再生・停止の位置
- 1／10フレームと5秒移動の意味
- IN点とOUT点の設定方法
- 選択範囲の見え方
- 高速とフレーム正確の違い
- 書き出しボタンの見つけやすさ
- エラーや処理中表示の分かりやすさ
- 画面全体の文字サイズと余白
- アプリ全体の軽さと反応

特に「説明を読まないと分からなかった操作」を記録してください。PoCでは、機能が動くことと同じくらい重要な評価項目です。

## 7. 既知の制限

- プロキシの容量表示と削除画面は未実装です。
- 高速モードは、選択範囲付近に利用可能なキーフレームがない特殊な動画では正確モードが必要です。
- P/Bフレームの詳細表示は未実装です。今回はキーフレームとGOP境界の理解しやすさを評価します。
- 可変フレームレートのフレーム番号表示はPoC方式です。編集位置自体は今後PTS基準へ固定します。
