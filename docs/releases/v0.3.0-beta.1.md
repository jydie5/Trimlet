# Trimlet v0.3.0 Beta 1

This source-only prerelease advances the native macOS application from a single-range proof of concept to a focused multi-range editing workflow. It also defines the interaction contract for the next Windows parity turn.

## macOS Beta highlights

- Create multiple non-overlapping subclips from one source video.
- Identify clips by representative thumbnails, editable stable names, and source IN–OUT time ranges.
- Reorder clips directly in the contiguous editing sequence, trim or remove them, and use Undo/Redo.
- Preview the active draft, one retained clip, or the complete sequence.
- Export the ordered sequence as one validated MP4 in Fast or frame-accurate mode.
- Select among multiple source audio streams.
- Distinguish the purple uncommitted IN/OUT draft from blue retained clips, with green IN and red OUT markers.
- Navigate with visible `J Reverse`, `K Stop`, and `L Forward` shuttle controls at 1x, 2x, 4x, and 8x.
- Set IN with `I`, set OUT with `O`, move by one or ten frames, jump by five seconds, and scrub continuously with an exact final seek.
- Keep keyframe inspection non-modal while retaining cancellable progress for proxy generation and export.

## Windows follow-up

Windows remains at `v0.3.0-early-access.1` with the foundational single-range workflow. The next Windows development turn should adopt the multi-range state model and keyboard discoverability described in:

- `apps/windows/handover.md`
- `docs/PLATFORM_CONTRACT.md`
- `contracts/edit-list.schema.json`

Windows should preserve the accepted behavior using WinUI-native controls and playback APIs rather than copying the SwiftUI layout or AVPlayer implementation.

## Build and run

This release contains source code only. On an Apple silicon Mac, install a Swift 6.1-compatible toolchain plus separate `ffmpeg` and `ffprobe`, then double-click `run-poc.command`. It builds an ad-hoc local application at `dist/Trimlet.app` without installing it system-wide.

No application bundle, DMG, installer, FFmpeg binary, ffprobe binary, or test video is attached to this release.

## Beta limitations

- Production signing, notarization, DMG distribution, and an original release icon are not complete.
- Accurate H.264/AAC settings remain provisional; VideoToolbox hardware encoding is preferred, but broader quality policy work remains.
- Long-media responsiveness, M2TS proxy behavior, A/V synchronization, cancellation, HDR/interlace/color metadata, and variable-frame-rate source-PTS navigation need broader real-machine evaluation.
- The editing sequence is contiguous and uses one source file. Gaps, overlaps, multiple tracks, transitions, titles, effects, and multiple source files are not implemented.
- FFmpeg and ffprobe must be installed separately and are governed by their own license terms.
