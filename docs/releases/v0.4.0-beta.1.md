# Trimlet 0.4.0 Beta 1 — Windows x64

Windows版のビルド済みアプリを初めて添付する、署名なしの試験配布です。

## ダウンロードと起動

**[Windows x64 ZIP](https://github.com/jydie5/Trimlet/releases/download/v0.4.0-beta.1/Trimlet-0.4.0-beta.1-win-x64.zip)** をすべて展開し、`Trimlet.Windows.exe` を起動してください。.NETとWindows App SDKのランタイムは同梱しています。PowerShell起動スクリプトは不要です。

**FFmpeg／ffprobeは別途必要です。** PATHまたは `TRIMLET_FFMPEG` / `TRIMLET_FFPROBE` で指定してください。[詳しい起動方法・制限](https://github.com/jydie5/Trimlet/blob/v0.4.0-beta.1/apps/windows/BETA_DOWNLOAD.md)。

## 更新内容

- 複数区間の切り出し・並べ替え・1本のMP4への書き出し。
- `.trimlet`プロジェクトの保存／再開／名前を付けて保存、元動画の再指定、未保存確認。
- 独立したIN／OUTつまみと、ズーム・表示移動・範囲に合わせる操作。
- READMEにアプリ全体の紹介画像と、デモ素材の生成手順ページを掲載。

## 確認結果と注意点

展開したZIPで起動、動画／プロジェクト読込、保存、書き出しを確認済み。35テストとFFmpeg結合テストに合格しています。[検証記録](https://github.com/jydie5/Trimlet/blob/v0.4.0-beta.1/apps/windows/BETA_RELEASE_VERIFICATION.md)。

署名・クリーン環境・幅広い動画／操作条件の検証は未完了です。Windowsが発行元の警告を表示する可能性があります。重要なプロジェクトはバックアップし、出力動画を確認してください。FFmpeg、デモ動画、Macバイナリは添付しません。Macの既存 `v0.3.0-beta.1` は変更しません。

ZIPには利用手順、ライセンス、依存関係一覧、ファイルハッシュ一覧を同梱しています。同梱Microsoftコンポーネントには各ライセンス条件が適用されます。添付の `SHA256SUMS.txt` でZIPを照合できます。

## English

First unsigned Windows x64 portable binary beta. Extract the entire ZIP and run `Trimlet.Windows.exe`; .NET and Windows App SDK runtime files are included. FFmpeg and ffprobe must be installed separately. Includes project persistence/source relinking and the build 10 timeline interaction, alongside multi-range editing/export. Archive launch, project save and synthetic-media export were smoke-tested on the developer's Windows 11 machine. Clean-machine, signing and expanded human/media acceptance remain pending. No Mac binary is included; existing Mac releases are unchanged.
