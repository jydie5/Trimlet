# Trimlet 0.4.0 Beta 2 — Windows x64

**FFmpegの手動設定が不要になりました。**

[Windows版をダウンロード](https://github.com/jydie5/Trimlet/releases/download/v0.4.0-beta.2/Trimlet-0.4.0-beta.2-win-x64.zip)し、すべて展開して `Trimlet.Windows.exe` を起動してください。

初回は **動画ツール → 同意して準備する**。取得元とライセンスを確認して同意すると、約71MBの動画ツールを自動で準備します。コマンド、手動コピー、管理者権限は不要です。.NETは引き続き同梱しています。

[はじめて使う方へ](https://github.com/jydie5/Trimlet/blob/main/docs/user-guide.ja.md)

## 取得するものと通信

- FFmpegはTrimletとは独立したソフトウェアです。TrimletのZIPには同梱せず、同意後にBtbNのGitHub配布ページから固定版を直接取得します。
- 初回のみネット接続が必要です。準備後はオフラインで編集できます。動画は送信せず、取得先へ通常の接続情報が送られます。
- 対象は実物のライセンス・構成を確認したLGPL 3.0版です。サイズ・SHA-256を検証し、検証に失敗したファイルは利用しません。キャンセルと再試行に対応します。
- [配布元・バージョン・ライセンスとソースへの参照](https://github.com/jydie5/Trimlet/blob/v0.4.0-beta.2/docs/legal/VIDEO_TOOL_ACQUISITION.md)。アプリの「動画ツール」からも確認できます。配布元で削除された場合は取得できません。

未署名のWindows x64試験版です。クリーン環境や幅広い動画・操作条件の確認は継続中です。Macバイナリは含みません。著作権・コーデック特許の包括的な法的保証ではなく、商用利用・再配布などで必要な専門的確認を代替しません。既存Beta 1の添付ファイルは変更しません。

## English

No more manual FFmpeg configuration. Extract the Windows ZIP, run the app, then choose **Video tools → Agree and prepare**. The app asks for agreement before downloading a pinned LGPL 3.0 FFmpeg build directly from BtbN's GitHub release. Initial internet access is required; no video is uploaded. Size and SHA-256 verification precede extraction. .NET is included; FFmpeg is acquired separately by the app, not bundled in the release ZIP. Unsigned experimental x64 beta; no clean-machine certification or comprehensive legal/patent clearance is claimed.
