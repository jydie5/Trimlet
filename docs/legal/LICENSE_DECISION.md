# Project license decision

- Status: Accepted
- Updated: 2026-08-16

## Decision

Use the MIT License for Trimlet source code and documentation, matching the author's MangaCrisp project.

The owner does not seek royalties or personal attribution and intends Trimlet to be free software with an optional donation path. The MIT License grants broad permission to use, copy, modify, publish, distribute, sublicense, and sell copies, subject to preserving its notice and disclaimer.

## Comparison

| Question | Apache-2.0 | MIT |
|---|---|---|
| Permissive commercial use | Yes | Yes |
| Source disclosure required for Trimlet modifications | No | No |
| Explicit contributor patent grant | Yes | No explicit grant |
| Notice handling | More detailed | Very simple |
| Selected here | No | Yes |

This choice governs Trimlet source only. It does not relicense FFmpeg, Apple assets, operating-system frameworks, codecs, contributor media, or other third-party material.

## Copyright notice

The collective notice is:

```text
Copyright (c) 2026 Trimlet contributors
```

This avoids requiring the author's personal name while retaining a conventional MIT notice. Copyright arises automatically; the license is the broad permission given to everyone. Optional donations do not modify or condition that permission.
