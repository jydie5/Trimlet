# Supporting Trimlet

Trimlet is free, MIT-licensed software. If it is useful, users may voluntarily support continued development through the project's official link:

https://buymeacoffee.com/jydie5

Support is optional. Payment does not unlock features, change the license, create a support contract, grant product influence, or receive priority over non-paying users.

Development can also be supported at no cost by starring or sharing the repository, reporting reproducible problems with synthetic media, testing on different Macs or Windows PCs, and improving code or documentation.

Use only the support link published in this repository or in the application. Trimlet will not request payment through video files, exported files, error dialogs, or unsolicited messages.
