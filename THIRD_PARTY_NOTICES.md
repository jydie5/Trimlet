# Third-party notices

## Current source repository

The Trimlet source repository does not include FFmpeg, ffprobe, codec libraries, Apple SF Symbols artwork, or third-party sample media.

## FFmpeg and ffprobe

The macOS proof of concept launches a separately installed `ffmpeg` or `ffprobe` executable as an external process. FFmpeg is an independent project and is available under LGPL and, depending on build configuration, GPL terms.

- Project: https://ffmpeg.org/
- License and legal information: https://ffmpeg.org/legal.html
- Source: https://ffmpeg.org/download.html

Users and distributors are responsible for the license profile of the FFmpeg build they install or redistribute. A distributable Trimlet package must not copy a developer-machine or Homebrew FFmpeg binary into the application bundle without a separate compliance review.

## Apple SF Symbols

The macOS source references system-provided SF Symbols by name for interface controls. No SF Symbols artwork is included in this repository. SF Symbols must not be used as the Trimlet application icon, logo, or trademark.

Apple usage guidance: https://developer.apple.com/design/human-interface-guidelines/sf-symbols

## Test media

Test media generated by local scripts is stored under the ignored `TestMedia/` directory and is not part of the source distribution. Contributors must not commit personal, licensed, or otherwise restricted media without documented permission.
